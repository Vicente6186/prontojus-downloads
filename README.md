# ProntoJus — downloads

Repositório dedicado à distribuição oficial dos instaladores do ProntoJus e de seus comprovantes públicos de integridade.

Os arquivos ficam disponíveis na seção **Releases** após a conclusão das verificações de publicação. A ausência de uma versão publicada significa que não há instalador liberado neste canal.

Este repositório não contém o código-fonte privado do produto. As licenças dos componentes de terceiros acompanham os respectivos instaladores.

As versões publicadas usam releases imutáveis. Os arquivos e seus comprovantes devem ser verificados juntos; um arquivo de teste ou uma compilação local não equivale a uma versão comercial aprovada.
